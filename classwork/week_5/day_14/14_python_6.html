Sets

A Problem

  • Let’s revisit the Brontë sisters:
sisters = ["Charlotte", "Emily", "Anne", "Charlotte", "Emily", "Charlotte"]
  • How many sisters are named here? How many unique names? Lists don’t have a built-in way to answer the second question.

Introducing Sets

  • A set is built exactly for “what are the unique items here?”
  • Marked with curly braces {...} (like a dict), but holds single values (like a list). No duplicates, no order.
unique_sisters = set(sisters)
print(unique_sisters)
# {'Charlotte', 'Emily', 'Anne'}  -- order not guaranteed!
  • Try unique_sisters[0] — what happens? Why?

Sets in Action

unique_sisters.add("Branwell")
"Emily" in unique_sisters       # fast membership check
  • Set math, using two novels’ vocabularies:
jane_eyre_vocab = {"orphan", "governess", "moor", "fire", "love"}
wuthering_heights_vocab = {"moor", "ghost", "revenge", "love", "storm"}

jane_eyre_vocab | wuthering_heights_vocab   # union: either novel
jane_eyre_vocab & wuthering_heights_vocab   # intersection: both novels
jane_eyre_vocab - wuthering_heights_vocab   # difference: only Jane Eyre

Types vs. Tokens

Types vs. Tokens

  • A key linguistic distinction: how many words total (tokens) vs. how many different words (types)?
words = ["the", "cat", "sat", "on", "the", "mat", "the", "cat"]
tokens = len(words)          # 8
types = len(set(words))      # 5
  • This is one of the most common ways we’ll use sets in this course: turning a list into a set just to count how many different things are in it.

Type-Token Ratio

  • Type-token ratio (TTR) = types ÷ tokens — a real measure linguists use to describe how varied a text’s vocabulary is.
  • A text that repeats the same words a lot (casual speech, a child’s early writing) has a low TTR.
  • A text with rich, varied vocabulary has a higher TTR.
  • A set is what makes this measurement possible in a single line of code.

print(ttr)

Why Sets Are Useful for Us

  • Deduplicating: unique vocabulary, unique phonemes, unique speakers in a dataset.
  • Comparing two texts or language varieties: shared vs. unique vocabulary, using |, &, -.
  • Later this semester (WordNet), sets are what keep you from revisiting the same word meaning twice while exploring a network of related words.

Part 1: Tokens and Types

  2. How many types (unique words) are in each passage?

Part 2: Comparing the Passages

Part 3: Back to Lists

Activity Answers

Part 1: Tokens and Types

# Austen
print(len(austen_opening))            # 23 tokens
print(len(set(austen_opening)))       # 18 types
print(len(set(austen_opening)) / len(austen_opening))   # TTR ~ 0.78

# Bronte
print(len(bronte_opening))            # 23 tokens
print(len(set(bronte_opening)))       # 21 types
print(len(set(bronte_opening)) / len(bronte_opening))   # TTR ~ 0.91
  • Same number of tokens, but the Brontë passage has a higher type-token ratio — Austen’s famous opening line leans on repetition ("a" four times) in a way this stretch of Brontë doesn’t.

Part 2: Comparing the Passages

austen_words = set(austen_opening)
bronte_words = set(bronte_opening)

print(austen_words & bronte_words)
# {'a', 'in', 'of', 'that'}   -- small function words, not content words

print(austen_words - bronte_words)
# the 14 words unique to the Austen passage

Part 3: Back to Lists

print(austen_opening.count("a"))   # 4
print("a" in austen_words)         # True -- but that's all a set can tell you
